# Voyager

Voyager is a modern, responsive web gateway designed to provide a faster, cleaner, and more focused way to explore the open web. It features a sleek dark interface with vibrant gradients, smooth animations, and convenient shortcuts to frequently visited websites.

## Features

- **Modern interface**  
  Dark, futuristic design with gradient accents, glowing effects, and glassmorphism styling.

- **Website launcher**  
  Enter a website URL and launch it directly from the main search bar.

- **Quick navigation**  
  Built-in shortcuts for popular services, including:
  - Google
  - YouTube
  - Wikipedia
  - Reddit
  - GitHub
  - Twitch

- **Responsive design**  
  Optimized for desktop, tablet, and mobile devices.

- **About modal**  
  Includes an informational popup describing Voyager and its purpose.

- **Interactive UI**  
  Hover effects, active navigation states, animated cards, and smooth transitions create an engaging browsing experience.

- **Privacy-focused concept**  
  Voyager provides a clean browsing starting point without unnecessary visual clutter.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Responsive CSS media queries

## Usage

1. Clone or download the repository.
2. Open the HTML file in your browser.
3. Enter a website address into the launcher.
4. Click **Launch** to visit the selected website.

> Voyager is currently a frontend interface. A backend proxy is not included in this version.
